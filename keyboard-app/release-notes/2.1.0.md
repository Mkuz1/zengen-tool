## MK Board 2.1.0

- **In-app updates.** MK Board checks this page for new versions, notifies you, and installs updates for you (Android shows a confirmation).
- **Liquid Glass** design for the iPhone-style keyboard: a frosted, see-through sheet with glass keys.
- **Tablets and foldables:** an iPad-style layout with swipe-down numbers and symbols; the keyboard re-lays itself out when you fold or unfold.
- BlackBerry-style keyboard stays centred on wide screens.
- New MK Board name and icon.

**Upgrading from 2.0 or older:** builds before 2.1.0 were signed with a temporary key. Uninstall the old app once, then install this APK. Future updates install automatically from inside the app.
